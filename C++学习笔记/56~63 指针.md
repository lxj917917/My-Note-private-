二、指针所占内存空间
![[Pasted image 20260730113241.png]]
sizeof (int * )      占四个字节
32位系统，所有类型指针都是4个字节
64位系统，所有类型指针都是8个字节

三、空指针
![[Pasted image 20260730114354.png]]
1.空指针用于给指针变量初始化
2.空指针是不可进行访问的
（0~255的内存空间是系统占用的，因此不能访问）

五、const修饰指针
![[Pasted image 20260730142032.png]]
1.常量指针
const int * p = &a；
![[Pasted image 20260730142444.png]]此时指针的指向可以修改，但是指针指向的值不可以修改
2.指针常量
int * const p = a；
![[Pasted image 20260730143125.png]]
此时指针的指向不能修改，指针指向的值可以修改
3.const既修饰指针，又修饰常量
const int * const p = a;
![[Pasted image 20260730143458.png]]
指针的指向，指针指向的值都不可修改
